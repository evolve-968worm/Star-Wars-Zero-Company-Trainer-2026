## 🎮 About the Game

STAR WARS Zero Company™ is a single-player, turn-based tactics game released on August 27, 2026. It was developed by Bit Reactor in collaboration with Respawn Entertainment and Lucasfilm Games. Set during the twilight of the Clone Wars, it combines squad-based combat, strategic operations, investigations, character customization, and cinematic storytelling.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **STAR WARS Zero Company™**. This trainer enhances the game's tactical systems by providing control over operator health, action points, Advantage points, mission resources, injuries, and combat outcomes. It is designed for the single-player campaign and supports the game's turn-based missions, squad management, and base operations.

**Target Audience:** Players who want a more forgiving campaign, faster experimentation with squad builds, easier mission retries, or additional control over the strategic and tactical systems.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combat movement is turn-based and consumes action points. Select an operator, choose a highlighted destination, and use the unlimited action point option when you want to reposition repeatedly, reach cover, or combine movement with attacks during the same turn.

### Tools & Inventory

Operators use customizable appearances, loadouts, abilities, and combat specializations. Apply resource options before purchasing or changing equipment, then configure each squad member at the Den or during campaign preparation.

### World & Environment

The Den serves as Zero Company's base of operations. Missions advance the campaign, while non-combat operations consume Intel and can provide items, credits, Influence, and relationship effects. Resource options are useful when managing several available activities in the same cycle.

### Combat & Weapons

Each operator has health and three action points. Use the trainer before issuing orders to enable unlimited health, Advantage, or action points. Overwatch, Rally, ranged attacks, melee attacks, backup assists, and special abilities can then be used without normal resource pressure.
